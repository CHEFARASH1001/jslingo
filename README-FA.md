# JSLingo

> یادگیری JavaScript، تمرین واقعی، پیشرفت مرحله‌به‌مرحله.

JSLingo یک آزمایشگاه تعاملی و فارسی‌محور برای یادگیری JavaScript است. پروژه مسیر یادگیری را به درس‌های کوتاه، کوییز، تمرین کدنویسی، مباحث شبکه، پروژه‌ی REST API و تمرین‌های آموزشی امنیت وب تقسیم می‌کند.

## امکانات

- مسیر مرحله‌ای یادگیری JavaScript از مفاهیم پایه تا مباحث مدرن
- آموزش شبکه، DNS، HTTP/TLS، پورت‌ها، پروکسی و ابزارهای پایه
- چلنج‌های الگوریتمی و تمرین‌های Promise، Closure و Frontend
- مسیر ساخت REST API با توضیحات معماری، تست و Docker
- ذخیره‌ی XP و پیشرفت در `localStorage` مرورگر
- محیط تمرین با Web Worker و توقف کدهای بی‌نهایت
- اجرای ساده و reproducible با Docker و Nginx

## اجرا با Docker

```bash
docker compose up --build
```

سپس برنامه را در [http://localhost:4200](http://localhost:4200) باز کن. برای توقف:

```bash
docker compose down
```

## اجرای محلی

```bash
python3 -m http.server 4173
```

بعد به [http://localhost:4173](http://localhost:4173) برو.

## نکته‌ی امنیتی

بخش امنیت فقط برای یادگیری و تست روی سیستم‌هایی است که مالک آن‌ها هستی یا اجازه‌ی صریح برای تستشان داری. نمونه‌های داخل درس‌ها آموزشی و ساختگی هستند؛ بدون مجوز روی سرویس‌های دیگران اجرا نشوند.
